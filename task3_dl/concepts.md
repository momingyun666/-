# 深度学习基础概念

## 一、神经网络基础

### 1. 神经元与感知机

神经元是神经网络的最小计算单元。它先对输入做加权求和，再加上偏置，最后经过激活函数：

```text
z = w1*x1 + w2*x2 + ... + wn*xn + b
a = f(z)
```

其中 `x` 是输入，`w` 是权重，`b` 是偏置，`f` 是激活函数，`a` 是输出。

感知机可以看作最简单的神经元：输入经过加权和后被阈值函数判断为 0 或 1。单层感知机只能解决线性可分问题，例如简单的“与”“或”逻辑，但不能解决异或问题。多层网络和非线性激活函数使模型能够表达更复杂的函数。

### 2. 权重与偏置

- **权重**决定某个输入对输出的影响程度。权重越大，该输入的变化通常越能改变输出。
- **偏置**决定神经元在输入全为零时的基础响应，相当于把决策边界整体平移。

训练神经网络的过程，本质上就是不断调整所有权重和偏置，使预测值更接近真实标签。

### 3. 激活函数

如果没有激活函数，多层线性层叠加后仍然等价于一个线性变换，网络再深也无法拟合非线性关系。常见激活函数有：

- **Sigmoid**：`1 / (1 + exp(-x))`，输出在 `(0,1)`，适合二分类概率，但深层网络中容易出现梯度消失。
- **Tanh**：输出在 `(-1,1)`，零中心化，但仍可能出现梯度消失。
- **ReLU**：`max(0,x)`，计算简单、正区间梯度稳定，是 MLP 和 CNN 中最常用的激活函数之一。
- **Softmax**：把多个输出转换成概率分布，常用于多分类网络的最后一层。MNIST 的 10 类分类通常配合交叉熵损失使用。

## 二、网络结构与前向传播

### 1. 前向传播

前向传播是数据从输入层依次经过隐藏层、输出层，最终得到预测值的过程：

```text
输入 x
  -> 第一层：z1 = W1*x + b1，a1 = f(z1)
  -> 第二层：z2 = W2*a1 + b2，a2 = f(z2)
  -> 输出层：logits = W3*a2 + b3
```

训练时，前向传播得到预测值后，用损失函数衡量预测值与标签之间的差距。

### 2. 隐藏层与输出层

- **隐藏层**位于输入层和输出层之间，负责从原始特征中学习中间表示。隐藏层越多、越宽，模型容量通常越大，但也更容易过拟合、训练更慢。
- **输出层**根据任务决定维度。MNIST 有 10 个类别，因此输出层有 10 个神经元；回归任务通常只需要 1 个输出。

### 3. 全连接层

全连接层（Fully Connected Layer，`nn.Linear`）中，每个输入神经元都与每个输出神经元相连：

```text
y = W*x + b
```

若输入维度是 784，输出维度是 512，则权重矩阵形状为 `512 x 784`，偏置形状为 `512`。MNIST 图片是 `28 x 28`，展平后得到 784 维向量，再送入全连接层。

## 三、训练与优化

### 1. 损失函数

损失函数衡量模型预测与真实目标之间的差距，训练目标是最小化损失。

- 回归常用 **均方误差 MSE**：`L = (1/N) * Σ(y_pred - y_true)^2`。
- 多分类常用 **交叉熵损失 CrossEntropyLoss**：

```text
L = -Σ y_true * log(y_pred)
```

PyTorch 的 `nn.CrossEntropyLoss` 内部包含 Softmax，因此网络输出层直接给 logits 即可，不需要手动再加 Softmax。

### 2. 梯度下降

梯度表示损失函数在某一点上升最快的方向，因此参数应沿着负梯度方向更新：

```text
θ_new = θ_old - learning_rate * gradient
```

按每次更新使用的数据量，可以分为：

- **批量梯度下降**：每次用全部训练数据计算梯度，稳定但计算量大；
- **随机梯度下降 SGD**：每次用一个样本更新，速度快但波动大；
- **小批量梯度下降**：每次用一个 batch，兼顾稳定性和效率，是深度学习中最常用的形式。

本项目曲线拟合使用全部训练样本计算梯度，属于批量梯度下降；MNIST 使用 batch size 128，属于小批量梯度下降。

### 3. 反向传播与链式法则

反向传播利用链式法则，从损失函数开始，逐层计算损失对每个参数的偏导数。

例如：

```text
z = W*a + b
a_next = f(z)
L = loss(a_next, y)
```

则：

```text
dL/dW = dL/dz * dz/dW
dL/db = dL/dz * dz/db
```

PyTorch 的 `loss.backward()` 会自动沿着计算图反向传播，把梯度累积到每个参数的 `.grad` 中；`optimizer.step()` 再根据这些梯度更新参数；`optimizer.zero_grad()` 用于清空上一轮梯度，防止梯度被重复累加。

### 4. 学习率

学习率决定每次参数更新的步长：

- 学习率过大：损失震荡甚至发散；
- 学习率过小：收敛很慢，可能停在较差的区域；
- 常见做法：先用较大学习率快速下降，再使用学习率衰减策略。

曲线拟合任务中，学习率过大时 `exp(a5*x1)` 可能迅速变得很大，因此代码中还对 `a5` 做了数值稳定处理。

### 5. 优化器

- **SGD**：最基础的梯度下降；
- **Momentum SGD**：引入动量，减少震荡，加快沿稳定方向的更新；
- **Adam**：同时使用一阶矩和二阶矩估计，为不同参数自适应调整学习率，通常收敛较快；
- **AdamW**：Adam 加解耦权重衰减，常用于 Transformer 等模型。

MNIST 任务使用 Adam，曲线拟合任务使用基础 SGD，以便直接展示梯度下降过程。

### 6. Epoch、Batch、Iteration

- **Batch**：一次前向/反向传播使用的样本数，例如 128；
- **Iteration**：完成一次参数更新，也就是处理完一个 batch；
- **Epoch**：完整遍历一次训练集。

MNIST 有 55000 个训练样本，batch size 为 128 时：

```text
iteration 数量 ≈ ceil(55000 / 128) = 430
```

因此训练 5 个 epoch 约进行 2150 次参数更新。

### 7. 混合精度训练

混合精度训练通常指前向传播和部分运算使用 FP16/BF16，而参数更新和部分敏感计算仍使用 FP32。它的优点是：

- 减少显存占用；
- 在支持 Tensor Core 的 GPU 上提高计算吞吐；
- 通过 `GradScaler` 防止 FP16 梯度下溢。

CPU 训练通常不能获得同样的加速收益，因此本项目在 CPU 上使用 FP32。混合精度更适合 CUDA GPU 上的大模型训练。

## 四、关键技巧与调参

### 1. 过拟合与欠拟合

- **欠拟合**：训练损失和验证损失都较高，模型连训练集规律都没有学好。可以增加模型容量、延长训练、减小正则化。
- **过拟合**：训练损失很低，但验证/测试损失明显更高，模型记住了训练样本而没有学到泛化规律。可以增加数据、使用 Dropout、L2 正则化、早停或减小模型。

### 2. 正则化

- **L1 正则化**：在损失中加入参数绝对值之和，倾向于产生稀疏权重，可用于特征选择；
- **L2 正则化**：在损失中加入参数平方和，使权重更平滑，常用形式是优化器的 `weight_decay`；
- **Dropout**：训练时随机把一部分神经元置零，迫使网络学习冗余表示，减少对某些神经元的依赖。

### 3. 批归一化 BatchNorm

BatchNorm 对每个 mini-batch 的隐藏层输出做归一化，再学习缩放参数 `γ` 和平移参数 `β`：

```text
x_hat = (x - mean) / sqrt(var + eps)
y = γ * x_hat + β
```

它可以稳定训练、加快收敛，并具有一定正则效果。注意训练模式和评估模式不同：训练时使用当前 batch 的统计量，评估时使用滑动平均统计量，因此测试前必须调用 `model.eval()`。

### 4. 训练集、验证集、测试集

- **训练集**：用于计算梯度、更新参数；
- **验证集**：用于选择超参数和最佳 epoch，不直接参与梯度更新；
- **测试集**：只在最后评估一次，代表模型对未见数据的泛化能力。

不能用测试集反复调参，否则测试集就间接参与了模型选择，评估结果会偏乐观。

本项目为了绘制题目要求的 Test Acc 曲线，会在每个 epoch 记录一次测试集指标，但模型选择只依据验证集，测试集不参与梯度更新。

## 五、工具与底层概念

### 1. Tensor

Tensor 是 PyTorch 中的多维数组，具有形状、数据类型和设备三个重要属性。例如：

```python
x = torch.randn(32, 1, 28, 28)
print(x.shape)   # [32, 1, 28, 28]
print(x.dtype)   # torch.float32
print(x.device)  # cpu 或 cuda
```

MNIST 一个 batch 的形状是 `[batch, 1, 28, 28]`，展平后变成 `[batch, 784]`。

### 2. 自动求导 Autograd

设置 `requires_grad=True` 的张量会被记录到计算图中。执行 `loss.backward()` 后，PyTorch 自动计算梯度并存入 `.grad`。这避免了手动推导和实现每一层的反向传播公式。

### 3. GPU 与 CPU

- CPU 核心少但通用，适合小模型、数据处理和串行逻辑；
- GPU 核心多、并行吞吐高，适合大规模矩阵乘法，是深度学习的常用硬件；
- GPU 训练需要把模型和数据都移动到同一设备，数据在 CPU/GPU 之间频繁传输会产生额外开销。

本项目环境是 CPU 版 PyTorch，因此 MNIST 训练在 CPU 上完成。
